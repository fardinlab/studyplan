# 📚 Student Study Planner

A modern and responsive study planning website for students.  
This project helps students organize their daily study routine, manage study tasks, set schedules, and track completed plans easily.

🌐 Live Website: https://fardinlab.dev/studyplan/

---

# ✨ Features
- ✅ Study Task Management
- ✅ Add Study Plans
- ✅ Set Date & Time
- ✅ Priority Selection
- ✅ Complete & Delete Tasks
- ✅ Local Storage Support
- ✅ Team Information Section
- ✅ Smooth User Experience

---
