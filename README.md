# 📚 Student Study Planner

A simple and user-friendly study planning website for students. This project helps students create study plans, set dates and times, choose task priority, and track completed study tasks.

## 🌐 Live Project Overview

**Student Study Planner** is a web-based project developed for students who want to manage their daily study routine in an organized way. Users can add study tasks, select a date, set start and end time, mark tasks as completed, and delete tasks when needed.

## ✨ Features

- 🧭 Clean and responsive navigation bar
- 🏠 Home section with project introduction
- 📌 Project details section
- 📝 Study planner form
- 📅 Add study task with date and time
- ⏰ Select start time and end time
- 🚦 Choose task priority
- ✅ Mark plans as completed
- 🗑️ Delete study plans
- 📊 Track total plans and completed plans
- ❓ FAQ section
- 💾 Local storage support to save plans in the browser
- 📱 Responsive design for desktop and mobile devices

## 🚀 How to Use

1. Open the website in a browser.
2. Go to the **Planner** section.
3. Enter the study task name.
4. Select the date.
5. Choose start time and end time.
6. Select task priority.
7. Click **Add Plan**.
8. Use **Complete** to mark a task as completed.
9. Use **Delete** to remove a task.

## 🎯 Project Purpose

Many students forget their study schedule or fail to manage study time properly. This website helps students create a simple study routine and track their progress easily.
